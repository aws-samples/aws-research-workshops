## AWS Research Workshops

This repo is the companion for [Research Computing Workshop](https://catalog.workshops.aws/research-computing).

## Contents

### Notebooks

- **[ParallelCluster](notebooks/parallelcluster/)** — Jupyter notebooks for AWS ParallelCluster workflows including Athena++ simulations, Slurm REST API client, job accounting, cluster federation, and cost estimation.
- **[Container](notebooks/container/)** — Notebooks covering container basics, CI/CD pipelines for research containers, and Singularity container workflows.
- **[SageMaker](notebooks/sagemaker/)** — Research data management with SageMaker.

### How-To Guides

- **[SageMaker Modulus Kernel](howto/sagemaker_modulus_kernel/)** — Build and register a custom NVIDIA Modulus kernel image for SageMaker Studio.

### Shared Libraries

- **[lib/](lib/)** — Helper modules (`workshop.py`, `tf_scripts.py`) used across notebooks.
